# favicon-source.png

ファビコン一式の生成元。`public/` の favicon.ico / favicon-32.png /
favicon-192.png / apple-touch-icon.png はすべてこの1枚から作っている。

このディレクトリのファイルは import しない限りビルドに含まれないので、
配信物には出ない（元画像 388KB がそのまま載るのを避けるため public/ ではなくここ）。

作り直すとき:

- タイル色は `--bg` の #0a0a1a、角丸は一辺の22%（旧ファビコンと同じ比率）
- マークはタイルの72%に収める。apple-touch-icon だけ iOS 側が角丸マスクを
  かけるので、角丸なし・不透明・68%
- マークがほぼ白なので、タイルなしで配信しないこと。白いタブバーで消える
